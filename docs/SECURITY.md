# 安全边界

## 不进入 Git 的内容

- 小红书 Cookie、API Token 和扫码会话。
- DeepSeek API Key。
- 企业微信 CLI 授权、机器人 Secret、群聊 ID、成员 ID。
- 真实客户线索、评论历史、发送回执、运行日志和在线文档缓存。
- 真实同行作者 ID、内部备注和库存原始 Excel。

提交前运行：

```bash
bash scripts/secret-scan.sh
```

## 平台操作限制

本项目只允许小红书搜索和详情读取。禁止自动评论、私信、点赞、关注、收藏、发布，以及通过换账号、频繁重试或其他方式绕过平台限制。正式使用前应自行确认账号类型、平台条款和当地法律允许的访问方式。

## 失败处理

- 验证码、`401`、`403`、`429`、访问限制或登录失效：持久暂停并告警一次。
- 本机后端断开：停止本轮，不把每个帖子伪装成独立失败。
- 企业微信明确失败：保留待发记录，下轮重试。
- 企业微信发送结果不确定：隔离本批并要求人工核查，不自动重发。
- 不把“接口已接受”表述为“群成员已阅读”。

## 文档权限

示例配置为 `public`，因为当前业务要求链接可直接打开。这会使拿到链接的人可读。若线索含个人信息，推荐把 `document_delivery.join` 改为 `read`（企业内部只读）或 `apply`（申请访问），并在测试群验证权限。
